# DuoKit (vendored)

The iPhone Duo layer: fold geometry, pose detection (flat / book / table / tent),
the two-sided override and the debug fold simulator.

This is a copy of DuoKit 0.1.2 (Gordon Shepherd's private repository, tag 0.1.2,
commit f850b95), vendored so Relics: Games builds from this repository alone.
