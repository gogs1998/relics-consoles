Free homebrew demos included with Relics: Consoles
================================================

Relics: Consoles includes five small games written by independent authors and
released under free licences. Each is an unmodified copy of the author's own
build, stored as a separate game file and run by the emulator like any other
game file you add. They are not part of the app's program code. You can delete
them from your shelf; they won't come back.

The authors did not make, endorse or sponsor Relics: Consoles.

Getting the source code
-----------------------
The complete source code of each GPL-licensed demo, for the exact version
included, is available at no charge from the addresses above. We also keep
the exact source archives of µCity 1.3, Thwaite 0.03 and Alex vs Bus pre3,
and will send them free of charge on request to gordon@iqlabs.app.

The seeded demo files are in the app's Games folder, which you can open in
the Files app.
